# Submission Reminder App - Isuwafa

A simple reminder application built with shell scripts to help manage and track submissions.

## Installation & Setup

### Step 1: Clone the Repository

bash
```
git clone https://github.com/Isuwafa/submission_reminder_app_Isuwafa.git
cd submission_reminder_app_Isuwafa
```

### Step 2: Make Scripts Executable

bash
```
chmod +x create_environment.sh
chmod +x copilot_shell_script.sh
```

## How to Run the Application

### Step 1: Create the Environment

First, run the environment setup script to prepare all necessary configurations and dependencies:

bash
```
./create_environment.sh
```

This script will:
- Set up the required directory structure
- Initialize configuration files
- Prepare the environment for the application

### Step 2: Run the Application

After successfully creating the environment, run the main application script:

bash
```
./copilot_shell_script.sh
```

This script will:
- Launch the reminder application
- Display the main interface
- Allow you to manage your submission reminders
